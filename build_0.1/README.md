# ЗУП: сравнение цен — тестовый билд 0.1

Десктопное приложение (Python + Tkinter), которое сравнивает цены в магазинах
**«Пятёрочка» (X5 Клуб)** и **«Магнит»** в городах Пензенской области.

> Билд 0.1 — первый тестовый. В нём из X5 Клуба только «Пятёрочка» (по договорённости).
> «Перекрёсток» и логотип появятся в следующих билдах.

## Что умеет билд 0.1 (из MVP)
- выбор города Пензенской области (запоминается между запусками);
- поиск товара сразу в двух сетях и сравнение цен (в том числе цена за кг/л, чтобы сравнивать упаковки разного размера);
- самый выгодный товар каждой сети подсвечен, сверху — короткий вывод «где выгоднее»;
- ссылка на товар на сайте магазина (двойной щелчок или кнопка);
- «Избранное» — сохранение товаров в локальную базу SQLite;
- прокси и cookie для обхода защиты «я не робот» (файл `settings.json`);
- демо-режим с вымышленными ценами — для проверки интерфейса без интернета.

## Установка и запуск (Windows)
Нужен Python 3.10 или новее (с галочкой *tcl/tk* при установке — она стоит по умолчанию).

```bat
cd путь\к\build_0.1
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py --demo
```

`--demo` — демо-режим. Без него приложение ходит на настоящие сайты:

```bat
python main.py
python main.py --city Кузнецк --query молоко
```

## Если сайт пишет «доступ запрещён» (HTTP 403)
У «Пятёрочки» сильная защита от ботов. Что делать:
1. Скопируйте `settings.example.json` в `settings.json`.
2. Откройте https://5ka.ru в Chrome, выберите магазин, нажмите F12 → вкладка *Network* →
   обновите страницу → любой запрос к `5d.5ka.ru` → в *Request Headers* скопируйте значение `Cookie`.
3. Вставьте его в `settings.json` в поле `pyaterochka_cookie`.
4. При необходимости укажите `proxy`, например `http://логин:пароль@хост:порт`.

Cookie живут недолго — при повторной ошибке скопируйте новые. Не публикуйте `settings.json` (он в `.gitignore`).

## Проверки (для разработчика)
```bat
pip install -r requirements-dev.txt
ruff check .
pytest
```
Тесты проходят без интернета (ответы сайтов подменены примерами в `tests/fixtures`).

## Структура
| Путь | Назначение |
|---|---|
| `main.py` | запуск, параметры `--demo --city --query` |
| `zup/gui.py` | окно Tkinter |
| `zup/compare.py` | поиск по сетям, сортировка, вывод «где выгоднее» |
| `zup/parsers/` | парсеры: `pyaterochka.py`, `magnit.py`, `demo.py` |
| `zup/http.py` | HTTP-запросы, прокси, понятные ошибки |
| `zup/storage.py` | SQLite: избранное и настройки |
| `zup/units.py` | цена за кг/л |
| `zup/config.py` | города, настройки |
| `tests/` | автотесты |
| `data/` | создаётся при запуске: `zup.db` (избранное), `zup.log` (журнал ошибок) |

## Известные ограничения билда 0.1
- Адреса API получены из открытых источников, а не из документации магазинов; формат ответов может измениться.
  Парсеры не проверены на живых сайтах из среды разработки — первая проверка за вами (см. `BUILD_NOTES.md`).
- Цены «Магнита» берутся из каталога «Магнит Экспресс» ближайшего к центру города магазина — они могут отличаться от цен на полке.
- Магазин выбирается автоматически (ближайший к центру города), отдельного выбора магазина нет.
