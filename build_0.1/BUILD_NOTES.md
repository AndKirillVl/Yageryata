# Заметки к билду 0.1

## Что проверить на своём компьютере
1. `python main.py --demo` — окно открывается, поиск «молоко» показывает таблицу, «★ В избранное» работает.
2. `python main.py` (без `--demo`), город «Пенза», товар «молоко»:
   - если нашлось в обеих сетях — парсеры работают;
   - если сообщение «доступ запрещён» — см. раздел про cookie в README;
   - любая другая ошибка — пришлите текст из окна и файл `data/zup.log`.
3. Нажмите двойным щелчком на товар — должна открыться страница на сайте магазина.
4. Перезапустите приложение — город и избранное должны сохраниться.
5. Смените город (например, Кузнецк) и повторите поиск.

## Что НЕ входит в билд 0.1
«Перекрёсток» (остальной X5 Клуб), показ акций (в MVP «желательно»), курьерство (вне MVP), логотип.
